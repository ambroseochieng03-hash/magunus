# MAGUNUS

**MAGUNUS** is a front-end supermarket web application designed to explore modern e-commerce interface design using HTML, CSS, and JavaScript.

The project demonstrates a supermarket shopping experience with product browsing, categories, branches, shopping cart functionality, checkout interfaces, customer interactions, and mobile-oriented design.

> **Project Status:** Learning and development project. This project is an official Magunas Supermarket website or commercial e-commerce platform.

---

## Features

### Shopping Interface

- Product browsing
- Product categories
- Product search interface
- Product cards
- Shopping cart
- Cart quantity management
- Order summary
- Checkout interface

### Supermarket

- Branch selection
- Branch information
- Delivery interface
- Promotional sections
- Product categories
- Supermarket navigation

### Customer Interface

- Customer profile interface
- Notification subscription
- Order confirmation interface
- Responsive navigation
- Mobile-friendly interface

### Payment Interface

- M-Pesa payment interface
- Card payment interface
- Payment method selection
- Checkout validation

> Payment functionality is simulated for demonstration purposes and does not process real transactions.

### Progressive Web App

The mobile implementation explores PWA-related functionality including:

- Service worker registration
- Web app installation
- Mobile viewport optimization
- Application manifest integration
- Mobile-oriented user interface
